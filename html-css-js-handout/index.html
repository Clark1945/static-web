第 0 章先看全貌：瀏覽器怎麼把檔案變成畫面

你在後端熟悉的是「請求進來、程式處理、回傳結果」。前端少了伺服器那一半：瀏覽器拿到檔案後，自己把它們變成畫面，之後還會在你的電腦上執行 JavaScript。流程大致是：

  1. 1. 解析 HTML建出 DOM 樹
  2. 2. 套用 CSS算出每個元素的樣式
  3. 3. 排版算出位置與大小
  4. 4. 繪製畫到螢幕上

JavaScript 執行時可以修改 DOM 或樣式，瀏覽器就會重做第 3、4 步。

Java 對照 瀏覽器可以想成一個會執行 JS 的 runtime，角色類似 JVM。差別是 JS 預設在單一執行緒上跑，靠事件迴圈處理等待（第 5 章）。

三種語言的分工

HTMLCSSJavaScript
負責內容與結構外觀與版面行為與互動
一句話頁面上有哪些東西它們長什麼樣子按了之後會發生什麼
是程式語言嗎不是，沒有條件與迴圈不是，是規則表是

三個檔案怎麼接在一起

index.html       結構，瀏覽器先下載這個
css/style.css    外觀，由 <link> 引入
js/app.js        行為，由 <script> 引入
<link rel="stylesheet" href="css/style.css">
<script defer src="js/app.js"></script>
為什麼要 defer 沒加 defer 而 script 又放在 <head> 時，腳本執行時 DOM 還沒建好，querySelector 會回傳 null。defer 讓腳本等 HTML 解析完才依序執行。

第 1 章HTML：頁面的結構

HTML 用標籤描述內容，瀏覽器把它解析成一棵 DOM 樹。一個最小的頁面長這樣：

<!doctype html>
<html lang="zh-Hant">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>頁面標題</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <h1>標題</h1>
  <p>一段文字，裡面有<a href="https://developer.mozilla.org/zh-TW/">連結</a>。</p>
  <script defer src="js/app.js"></script>
</body>
</html>
Java 對照 Thymeleaf 或 JSP 最後吐給瀏覽器的就是這種文字。前端只是把它直接寫出來。

常用標籤

用途標籤
文字h1 到 h6、p、strong、em、code
清單ul、ol、li
連結與圖片a href、img src alt
版面語意header、nav、main、section、article、aside、footer
通用盒子div（區塊）、span（行內）
互動button、input、label、select、textarea、details
表格table、tr、th、td

區塊元素（div、p、h1）獨占一整行；行內元素（span、a、strong）跟著文字流動。

語意比外觀重要 能用 <button> 就不要用 <div onclick>。按鈕天生可用鍵盤聚焦、按 Enter 觸發，螢幕閱讀器也認得它。

屬性：id、class、data-*

<article class="event major" id="tw-1895-cession" data-year="1895">
  • id：整頁唯一，用來定位，也是網址 #id 錨點。
  • class：可以有多個、可以重複，用來套樣式與選取元素。
  • data-*：自訂資料，JS 用 el.dataset.year 讀取。
  • aria-*：給輔助科技看的狀態，例如 aria-pressed="true"。
注意 重複的 id 不會報錯，但 getElementById 只會拿到第一個，很難除錯。

表單

用 <label> 把文字和輸入框綁在一起，點文字就會聚焦輸入框。<button> 在表單裡預設是送出，不想送出就寫 type="button"。

第 2 章CSS：外觀與版面

CSS 是一張規則表，每條規則由選擇器和宣告組成：

.event {            /* 選擇器：class 含 event 的元素 */
  padding: 12px;    /* 屬性: 值; */
  border: 1px solid #ccc;
}

引入方式有三種：外部檔案（<link>，建議）、<style> 區塊、元素上的 style="..."（只適合臨時除錯）。

選擇器

寫法意思
p所有 p 標籤
.cardclass 含 card
#topid 為 top
.a .b.a 底下任何層級的 .b（後代）
.a > .b.a 的直接子層 .b
.a, .b兩者都套用
a:hover、button:focus-visible偽類：特定狀態
input[type="search"]屬性選擇器
.event::before偽元素：在元素前面生出一個內容
.event.major同時有 event 和 major 兩個 class

層疊與特異性：誰會贏

同一個屬性被多條規則命中時，特異性高的贏：行內 style，大於 #id，大於 .class、屬性、偽類，大於標籤。同等級時，寫在後面的贏。!important 能蓋過一切，但會讓之後難以維護，盡量不用。

Java 對照 有點像 Spring 的設定覆寫：application.yml 的值會被環境變數蓋掉，優先順序決定誰生效。

試試看：把 #special 那條規則刪掉，看第三行變成什麼顏色。

盒模型

每個元素都是一個盒子，由內而外是：content（內容）、padding（內距）、border（框線）、margin（外距）。預設 width 只算 content，加了 padding 和 border 會讓盒子變寬，很反直覺。所以幾乎每個專案第一條都是：

*, *::before, *::after { box-sizing: border-box; }

這樣 width 就包含 padding 與 border。

常用單位

  • px：固定像素。rem：相對根字級（預設 16px），適合字體與間距。
  • %：相對父層。vw / vh：相對視窗寬高。dvh：手機網址列伸縮時會跟著變的視窗高度。
  • fr：Grid 專用，剩餘空間的份數。

Flexbox：一維排列

把容器設成 display: flex，子元素就沿著一個方向排列。兩個最常調的屬性：justify-content 管主軸（預設水平），align-items 管交叉軸（預設垂直）。

.row {
  display: flex;
  gap: 12px;                       /* 子元素間距 */
  justify-content: space-between;  /* 主軸分配 */
  align-items: center;             /* 交叉軸對齊 */
  flex-wrap: wrap;                 /* 放不下就換行 */
}

試試看：把 justify-content 改成 center、space-between；把 align-items 改成 center、stretch；加上 flex-direction: column。

Grid：二維排列

要同時控制橫排與直排時用 Grid。歷史資料庫的時間軸就是一個 Grid：左邊一欄年份，右邊每個國家一欄。

.grid {
  display: grid;
  grid-template-columns: 96px repeat(2, minmax(0, 1fr));  /* 年份欄 + 兩個國家欄 */
  gap: 12px;
}

這個預覽很窄，用 auto-fill 加 minmax 就能不寫 media query 而自動調整欄數。試試看：把 110px 改成 60px。

position：定位

值行為
static預設，照正常流程排版
relative以自己原本的位置為基準偏移；同時是子層 absolute 的參考點
absolute脫離正常流程，相對「最近的有定位的祖先」
fixed相對視窗，捲動時不動
sticky平時正常，捲到門檻（如 top: 0）後黏住

試試看：把 .scroll 的 overflow: auto 刪掉，sticky 就失效了。

歷史網站的關鍵 sticky 只在「會捲動的容器」裡有效。所以 .scroller 要設高度並 overflow: auto，表頭與年份欄才會固定。

CSS 變數、深色模式與響應式

:root { --bg: #fff; --ink: #111; }

@media (prefers-color-scheme: dark) {
  :root { --bg: #111; --ink: #eee; }
}

body { background: var(--bg); color: var(--ink); }

/* 行動版優先：先寫手機，再往大螢幕加 */
.card { padding: 12px; }
@media (min-width: 768px) { .card { padding: 24px; } }

/* 字級在 16px 到 22px 之間隨視窗寬度縮放 */
h1 { font-size: clamp(16px, 2.5vw, 22px); }

所有顏色都放進變數，換主題或做深色模式時只要改變數。別忘了 HTML 的 <meta name="viewport">，沒有它手機會把頁面縮成桌面版。

第 3 章JavaScript 語言基礎

JS 是動態型別、單執行緒、事件驅動的語言。想試任何一行，按 F12 開瀏覽器的 Console 直接貼上就能執行。

變數與型別

const name = "Clark";   // 不會被重新指派，預設用這個
let count = 0;          // 會改變才用 let
count += 1;
// 不要用 var

typeof "a"        // "string"
typeof 42         // "number"（整數和小數都是 number）
typeof true       // "boolean"
typeof undefined  // "undefined"
typeof null       // "object"（歷史包袱）
typeof [1, 2]     // "object"（判斷陣列要用 Array.isArray）
Java 對照 const 像 final：不能重新指派，但物件內容仍然可以改。

比較與真假值

0 == "0"     // true，會偷偷轉型，別用
0 === "0"    // false，永遠用 ===

// falsy（當成 false）：false, 0, "", null, undefined, NaN
if ("") { /* 不會進來 */ }

?? 只在值是 null 或 undefined 時才用預設；|| 連 0 和空字串都會被取代。?. 讓中途遇到 null 時不報錯。

const era = event.era ?? "未分類";
const first = country?.events?.[0]?.title;
const msg = `共 ${total} 筆事件`;   // 模板字串，用反引號

函式

function add(a, b) { return a + b; }
const add2 = (a, b) => a + b;                // 箭頭函式
const greet = (name = "訪客") => `哈囉，${name}`; // 預設參數
Java 對照 箭頭函式就是 lambda。函式是一等公民，可以當參數傳、當值回傳，後面的 map、filter、事件監聽都靠這點。

物件與陣列

const e = { year: 1895, title: "馬關條約", major: true };
const { year, title } = e;            // 解構
const copy = { ...e, major: false };  // 展開：複製並覆寫

const years = [1624, 1662, 1683];
const [first, ...rest] = years;       // first = 1624, rest = [1662, 1683]

陣列方法（對照 Stream）

JSJava Stream用途
mapmap一對一轉換
filterfilter篩選
findfilter().findFirst()找第一個符合的
some / everyanyMatch / allMatch是否有 / 是否全部
reducereduce聚合成一個值
sortsorted排序，會改動原陣列
兩個經典陷阱 sort() 沒給比較函式時，會把元素轉成字串再比，所以 [10, 9, 1] 會變 [1, 10, 9]。另外它直接改原陣列，所以先用 [...arr] 複製。下面的範例會示範。

JSON

const text = JSON.stringify({ year: 1895 });  // '{"year":1895}'
const obj  = JSON.parse(text);                // { year: 1895 }

JS 物件字面量和 JSON 長得很像，但 JSON 的 key 一定要雙引號、不能有註解與結尾逗號。

檔案怎麼拆：本專案不用 ES module

現代 JS 可以用 import / export 拆檔，但 <script type="module"> 在雙擊開啟（file://）時會被瀏覽器擋下。所以歷史資料庫用一般 <script>，每支檔案包在 IIFE（立即執行函式）裡，避免變數洩漏到全域：

(function () {
  "use strict";
  const secret = 1;   // 外面看不到
})();

第 4 章DOM 與事件：讓頁面動起來

DOM 是瀏覽器把 HTML 轉成的物件樹，JS 透過全域的 document 讀寫它。

const el = document.querySelector("#stats");        // 第一個符合的元素，沒有就是 null
const cards = document.querySelectorAll(".event");  // 全部符合的

el.textContent = "共 55 筆事件";        // 當純文字寫入
el.classList.add("active");             // 增減 class
el.dataset.year;                        // 讀 data-year
el.setAttribute("aria-pressed", "true");

const li = document.createElement("li");
li.textContent = "新項目";
document.querySelector("ul").append(li);
安全 innerHTML 會把字串當 HTML 解析，字串若含使用者輸入就是 XSS 漏洞。優先用 textContent 與 createElement。

事件

button.addEventListener("click", (event) => {
  console.log("被點了", event.target);
});

常用事件：click、input（輸入框每次變動）、change、submit、keydown、scroll、hashchange。event.preventDefault() 能擋掉預設行為，例如連結跳轉或表單送出。

事件委派

不要替每個按鈕各綁一個監聽器，而是綁在父層一次，再用 event.target.closest(選擇器) 找出實際被點的元素。好處是動態新增的元素不用重新綁定。歷史資料庫的事件標題連結就是這樣處理：

grid.addEventListener("click", (ev) => {
  const a = ev.target.closest("a.anchor");
  if (!a) return;           // 點到別的地方就忽略
  ev.preventDefault();
  // ...
});

狀態 → 重繪

最容易維護的寫法是：資料放在 state，改了資料就呼叫 render() 整個重畫，不要東改一點西改一點。這正是 React 之類框架的核心想法，只是它們幫你把「重畫」做得更有效率。

試試看：把 li.textContent 那行改成 li.innerHTML = text + " "，再新增一筆內容為 <b>粗體</b> 的待辦，觀察差別。這就是 XSS 的原理。

第 5 章非同步與瀏覽器 API

JS 在單一執行緒上跑，遇到網路請求、計時器這類要等的事，會交給瀏覽器處理，完成後再把回呼排進佇列，等目前的程式跑完才輪到它。所以等待時畫面不會卡住，但「誰先執行」要特別注意。

Java 對照 沒有多執行緒與鎖的問題，但有執行順序的問題。Promise 類似 CompletableFuture，fetch 類似 HttpClient。

順序是：同步程式先全部跑完，接著 Promise 的回呼（微任務），最後才是 setTimeout（即使是 0 毫秒也要排隊）。

Promise 與 async / await

async function loadJson(url) {
  const res = await fetch(url);                       // 等網路，但不卡畫面
  if (!res.ok) throw new Error("HTTP " + res.status); // fetch 遇到 404 不會自己丟錯
  return res.json();                                  // 也是 Promise
}

async function main() {
  try {
    const data = await loadJson("/data/taiwan.json");
    console.log(data.events.length);
  } catch (err) {
    console.error("載入失敗", err);
  }
}
main();
注意 await 只能在 async 函式裡用（ES module 的最上層除外）。fetch 對 404、500 不會丟例外，要自己檢查 res.ok。

後端工程師一定會遇到：CORS 與 file://

CORS：網頁向「不同來源」（網域、埠號不同）發請求時，瀏覽器會檢查回應有沒有 Access-Control-Allow-Origin 標頭，沒有就擋下。擋的是瀏覽器，curl 和 Postman 不受影響。在 Spring Boot 用 @CrossOrigin 或 CORS 設定來放行。

file://：直接雙擊開啟 HTML 時，瀏覽器會擋 fetch 讀本機檔案。這就是歷史資料庫把資料寫在 .js 用 <script> 載入，而不是用 JSON 加 fetch 的原因。想改用 JSON，就要先用 python3 -m http.server 之類的方式開本機伺服器。

localStorage

try {
  localStorage.setItem("theme", "dark");
  const theme = localStorage.getItem("theme");   // 沒有就是 null
} catch (e) {
  // 私密模式或被停用時會丟例外，要能照常運作
}

只能存字串，物件要先 JSON.stringify。它在同網站同瀏覽器內持久，但不是安全儲存，別放密碼或 token。

第 6 章實戰：拆解「全球歷史資料庫」

前面學的東西，在歷史資料庫裡都出現過。資料流只有三步：

  1. registry.js建立全域的 HistoryDB 註冊表
  2. data/taiwan.js呼叫 register() 交出資料
  3. app.js讀註冊表，渲染成時間軸

精讀一段

function visibleEvents(country) {
  const q = state.query.trim().toLowerCase();
  return country.events
    .filter((e) => {                       // 1. 篩選：只看重大 / 關鍵字
      if (state.majorOnly && !e.major) return false;
      if (q && !(e.title + e.summary).toLowerCase().includes(q)) return false;
      return true;
    })
    .sort((a, b) => a.year - b.year);      // 2. 依年份排序
Java 對照 約等於 events.stream().filter(...).sorted(Comparator.comparingInt(Event::year)).toList()。這裡的 sort 不會弄亂原資料，因為 filter 已經先產生了新陣列。

Chapter 0The big picture: how a browser turns files into a screen

On the backend you are used to "a request comes in, the program handles it, a response goes out". The frontend lacks the server half: the browser takes the files and turns them into a screen by itself, then keeps running JavaScript on the user's machine. Roughly:

  1. 1. Parse HTMLbuild the DOM tree
  2. 2. Apply CSSwork out each element's style
  3. 3. Layoutwork out position and size
  4. 4. Paintdraw to the screen

When JavaScript changes the DOM or a style, the browser repeats steps 3 and 4.

Java comparison Think of the browser as a runtime that executes JS, a role similar to the JVM. The difference is that JS runs on a single thread by default and handles waiting with an event loop (chapter 5).

How the three languages divide the work

Responsible forContent and structureAppearance and layoutBehavior and interaction
In one sentenceWhat is on the pageWhat it looks likeWhat happens when you click
A programming language?No: no conditions or loopsNo: it is a rule sheetYes

How the three files connect

<link rel="stylesheet" href="css/style.css">

Why defer Without defer, a script in <head> runs before the DOM exists, so querySelector returns null. defer makes the script wait until the HTML is parsed and then run in order.

Chapter 1HTML: the structure of a page

HTML describes content with tags, and the browser parses it into a DOM tree. A minimal page looks like this:

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Page title</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <h1>Heading</h1>
  <p>A paragraph with a <a href="https://developer.mozilla.org/en-US/">link</a>.</p>

Java comparison What Thymeleaf or JSP eventually sends to the browser is this kind of text. On the frontend you simply write it directly.

Block elements (div, p, h1) take a whole line. Inline elements (span, a, strong) flow along with the text.

Meaning beats looks If you can use <button>, do not use <div onclick>. A button can take keyboard focus and respond to Enter out of the box, and screen readers recognize it.

Attributes: id, class, data-*

<article class="event major" id="tw-1895-cession" data-year="1895">
  • id: unique on the page. Used to locate an element, and the target of a #id anchor in the URL.
  • class: can be multiple and can repeat. Used for styling and for selecting elements.
  • data-*: custom data. JS reads it with el.dataset.year.
  • aria-*: state for assistive technology, for example aria-pressed="true".
Watch out A duplicate id does not raise an error, but getElementById only returns the first one, which is hard to debug.

Forms

Use <label> to tie the text to the input, so clicking the text focuses the input. Inside a form, <button> submits by default. If you do not want that, write type="button".

Chapter 2CSS: appearance and layout

CSS is a sheet of rules. Each rule is made of a selector and declarations:

.event {            /* selector: elements whose class contains event */
  padding: 12px;    /* property: value; */
  border: 1px solid #ccc;
}

There are three ways to include it: an external file (<link>, recommended), a <style> block, or style="..." on an element (only for quick debugging).

The cascade and specificity: who wins

When several rules hit the same property, the one with higher specificity wins: inline style beats #id, which beats .class, attribute and pseudo-class, which beats a tag. At equal level, the later rule wins. !important beats everything, but it makes things hard to maintain later, so avoid it.

Java comparison A bit like Spring configuration overrides: a value in application.yml gets overridden by an environment variable. The priority order decides which one takes effect.

Try it: delete the #special rule and see what color the third line becomes.

The box model

Every element is a box. From the inside out: content, padding, border and margin. By default width only counts the content, so adding padding and border makes the box wider, which is counterintuitive. That is why almost every project starts with:

*, *::before, *::after { box-sizing: border-box; }

With that, width includes padding and border.

Common units

  • px: fixed pixels. rem: relative to the root font size (16px by default), good for fonts and spacing.
  • %: relative to the parent. vw / vh: relative to the viewport width and height. dvh: a viewport height that follows the mobile address bar as it shows and hides.
  • fr: Grid only, a share of the remaining space.

Flexbox: one-dimensional layout

Set a container to display: flex and its children line up along one direction. The two properties you will adjust most: justify-content controls the main axis (horizontal by default) and align-items controls the cross axis (vertical by default).

.row {
  display: flex;
  gap: 12px;                       /* space between children */
  justify-content: space-between;  /* distribute along the main axis */
  align-items: center;             /* align on the cross axis */
  flex-wrap: wrap;                 /* wrap when there is no room */
}

Try it: change justify-content to center or space-between; change align-items to center or stretch; add flex-direction: column.

Grid: two-dimensional layout

Use Grid when you need to control rows and columns at the same time. The timeline of the history site is a Grid: one column for years on the left, then one column per country.

.grid {
  display: grid;
  grid-template-columns: 96px repeat(2, minmax(0, 1fr));  /* year column + two country columns */
  gap: 12px;
}

This preview is narrow. auto-fill with minmax adjusts the number of columns without any media query. Try it: change 110px to 60px.

JS is a dynamically typed, single-threaded, event-driven language. To try any line, press F12 to open the browser Console and paste it in.

Variables and types

const name = "Clark";   // cannot be reassigned; use this by default
let count = 0;          // use let only when the value changes
count += 1;
// do not use var

typeof "a"        // "string"
typeof 42         // "number" (integers and decimals are both number)
typeof true       // "boolean"
typeof undefined  // "undefined"
typeof null       // "object" (a historical quirk)
typeof [1, 2]     // "object" (use Array.isArray to detect arrays)
Java comparison const is like final: you cannot reassign it, but the contents of an object can still change.

Comparison and truthiness

0 == "0"     // true; it converts types behind your back, avoid it
0 === "0"    // false; always use ===

// falsy (treated as false): false, 0, "", null, undefined, NaN
if ("") { /* never enters */ }

?? only falls back to the default when the value is null or undefined; || also replaces 0 and the empty string. ?. stops without an error when something in the chain is null.

const first = country?.events?.[0]?.title;
const msg = `${total} events in total`;   // template string, uses backticks

Functions

function add(a, b) { return a + b; }
const add2 = (a, b) => a + b;                    // arrow function
const greet = (name = "guest") => `Hello, ${name}`; // default parameter
Java comparison An arrow function is a lambda. Functions are first-class values: you can pass them as arguments and return them. map, filter and event listeners below all rely on that.

const years = [1624, 1662, 1683];

JSON

})();

Chapter 4DOM and events: making the page move

The DOM is the object tree the browser builds from HTML. JS reads and writes it through the global document.

const el = document.querySelector("#stats");        // first match, or null if none
const cards = document.querySelectorAll(".event");  // all matches

el.textContent = "55 events in total";  // write as plain text
el.classList.add("active");             // add or remove a class
el.dataset.year;                        // read data-year
el.setAttribute("aria-pressed", "true");

const li = document.createElement("li");
li.textContent = "New item";
document.querySelector("ul").append(li);
Security innerHTML parses a string as HTML. If that string contains user input, you have an XSS hole. Prefer textContent and createElement.

Events

button.addEventListener("click", (event) => {
  console.log("clicked", event.target);
});

Common events: click, input (every change in a text box), change, submit, keydown, scroll, hashchange. event.preventDefault() blocks the default behavior, such as following a link or submitting a form.

Event delegation

Do not attach a listener to every button. Attach one to the parent and use event.target.closest(selector) to find the element that was actually clicked. The benefit is that elements added later need no new listener. The event title links in the history site work this way:

grid.addEventListener("click", (ev) => {
  const a = ev.target.closest("a.anchor");
  if (!a) return;           // clicked somewhere else, ignore
  ev.preventDefault();
  // ...
});

State, then redraw

The easiest style to maintain is: keep data in a state object, and whenever it changes call render() to redraw everything, instead of patching the page a bit here and a bit there. This is the core idea of frameworks such as React, which just make the redrawing more efficient.

Try it: change the li.textContent line to li.innerHTML = text + " ", then add a to-do whose text is <b>bold</b> and look at the difference. That is how XSS works.

Chapter 5Async and browser APIs

JS runs on a single thread. When it hits something that has to wait, such as a network request or a timer, it hands the work to the browser, and the callback is queued for later. It only runs after the current code finishes. So the screen does not freeze while waiting, but you have to pay attention to "what runs first".

Java comparison There are no multithreading or lock problems, but there are ordering problems. A Promise is similar to CompletableFuture, and fetch is similar to HttpClient.

The order is: all synchronous code first, then Promise callbacks (microtasks), and setTimeout last (even 0 ms has to queue).

Promise and async / await

async function loadJson(url) {
  const res = await fetch(url);                       // wait for the network without freezing the page
  if (!res.ok) throw new Error("HTTP " + res.status); // fetch does not throw on 404 by itself
  return res.json();                                  // also a Promise
}

async function main() {
  try {
    const data = await loadJson("/data/taiwan.json");
    console.log(data.events.length);
  } catch (err) {
    console.error("Load failed", err);
  }
}
main();
Watch out await can only be used inside an async function (except at the top level of an ES module). fetch does not throw on 404 or 500, so check res.ok yourself.

Something every backend engineer runs into: CORS and file://

CORS: when a page sends a request to a different origin (different domain or port), the browser checks whether the response carries an Access-Control-Allow-Origin header, and blocks it if not. It is the browser that blocks it; curl and Postman are not affected. In Spring Boot, allow it with @CrossOrigin or a CORS configuration.

file://: when you open an HTML file by double-clicking, the browser blocks fetch from reading local files. That is why the history site puts its data in a .js file loaded with <script> instead of using JSON with fetch. To switch to JSON, first start a local server, for example with python3 -m http.server.

localStorage

try {
  localStorage.setItem("theme", "dark");
  const theme = localStorage.getItem("theme");   // null if missing
} catch (e) {
  // private mode or disabled storage throws; the page must still work
}

It only stores strings; run objects through JSON.stringify first. It persists within the same site and the same browser, but it is not secure storage, so never put passwords or tokens in it.

Common mistakes

  • Console shows Cannot read properties of null: querySelector found nothing. Check the selector, and make sure the script has defer.
  • CSS change has no effect: hard refresh with Ctrl+Shift+R, then check Computed in Elements to see whether another rule overrides it.
  • sort() gives odd order: numbers need a comparator.
  • Comparison gives odd results: change == to ===.
  • sticky does nothing: check whether an ancestor has overflow and whether you set top.
  • fetch fails locally: open the page through a local server, not file://.
