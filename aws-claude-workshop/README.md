# Claude on AWS 工作坊講義

AWS 官方「Claude on AWS」工作坊的繁體中文版，合併成單一 HTML 檔方便離線閱讀。共 251 頁，分成 13 個章節群（開始前、01～11 共 11 個模組、總結），內容完整保留，沒有刪減。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可，不需要 server、不需要建置。圖片已縮小後內嵌，檔案約 12 MB。

## 功能

- 左側目錄依模組分組，每個模組有自己的顏色與編號，只顯示目前章節；閱讀時目錄會標示目前頁面。
- 全文搜尋；勾選左下角「一次顯示全部章節」可顯示所有內容，方便 Ctrl+F。
- 程式碼區塊有複製按鈕；原文的提示框與可展開區塊都有保留。
- 深色模式、手機版、列印時自動展開所有章節。

## 內容來源

內容來自 AWS 官方工作坊的繁體中文匯出（Hugo 格式 Markdown），本資料夾的 `index.html` 是由那份 Markdown 轉換並重新排版的結果。原文有 8 個站內連結找不到對應頁面（不會跳轉），另有 29 張圖片在原始匯出中就缺檔。

公開散布前請先確認原始內容的授權。
